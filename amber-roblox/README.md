# Amber Alert — фан-ремейк для Roblox

Фан-ремейк хоррора **Amber Alert** (TEZ Studios). Весь код — в `src/`, файл места `AmberAlert.rbxlx`
собирается командой `python3 build.py`.

> Это фан-проект для обучения. Если будешь публиковать игру, дай ей своё название и свою обложку:
> копия чужой игры с тем же именем может получить жалобу.

## Как открыть
1. Roblox Studio → **File → Open from File** → `AmberAlert.rbxlx`.
2. **Play** (F5). Ты появишься в ночном лобби у лечебницы Black Ridge.
3. Зайди в одну из четырёх кабинок (Лёгкая / Средняя / Сложная / Бесконечная) и подожди 15 секунд.
4. Чтобы сохранялся прогресс (Amber, уровень, классы):
   1. **File → Publish to Roblox**.
   2. **Game Settings → Security → Enable Studio Access to API Services**.

## Как играть
- **День (7:00–21:00):**
  - собирай яблоки во дворе;
  - продавай их продавцу в гараже;
  - покупай батарейки, капканы, дробовик и другие предметы.
- **21:00:** телевизор включает экстренное оповещение. В нём сказано, кто сбежал и как выжить.
- **Ночь:**
  - заключённый вламывается через дверь или окно;
  - запирай двери (держи **R**);
  - прячься в шкафах и не проваливай концентрацию;
  - отбивайся предметами.
- **Рассвет (7:00):** погибшие оживают, двери чинятся, каждый получает +$40.
- Переживи все ночи — получишь Amber и опыт. За Amber в лобби покупаются классы.

## Управление
| Действие | Клавиши |
|---|---|
| Ходить / бег / присесть | WASD / Shift / C |
| Фонарик | F |
| Действие (двери, шкафы, яблоки, магазин) | E |
| Запереть / отпереть дверь | держать R |
| Предметы | 1–9, клик — использовать |
| Выйти из укрытия | E или пробел |
| Наблюдать после смерти | ← → |

На телефоне те же действия вынесены на кнопки на экране.

## Звуки и текстуры
Игра генерирует их сама: `python3 tools/gen_assets.py` → папки `assets/sounds`, `assets/images`.
Список файлов — в `assets/MANIFEST.md`. Чтобы они появились в игре:
1. Studio → **View → Asset Manager → Bulk Import** → выбери файлы из `assets/sounds` и `assets/images`.
2. Нажми правой кнопкой на загруженный файл → **Copy Asset ID**.
3. Вставь цифры в `ReplicatedStorage → Shared → Config`. Например: `Config.Sounds.EasTone = "1234567890"`.

Пустые ID просто означают тишину или отсутствие текстуры: игра не ломается.

## Как раскрыть ИИ-помощника на 100%
Сейчас я пишу код вслепую: Roblox Studio здесь нет, поэтому я проверяю код в своей «песочнице» (`tools/run_mock.py`).
Что сильно поднимет качество:
1. **Встроенный MCP-сервер Roblox Studio (лучший вариант).** В 2026 году в Studio появился встроенный MCP-сервер.
   Если запустить Claude Code на твоём компьютере и подключить его к Studio, я смогу сам:
   - запускать игру;
   - видеть ошибки и делать скриншоты;
   - генерировать 3D-модели и материалы;
   - вставлять ассеты из Creator Store.
   Настройка: включи в Studio встроенный MCP-сервер (раздел Assistant; инструкция — в анонсе на DevForum
   «Studio Built-in MCP Server») и подключи его к Claude Code на компьютере.
2. **Ключ Open Cloud.** Создай API-ключ с правом загрузки ассетов (Creator Hub → Open Cloud → API Keys),
   положи его в секреты окружения Claude и открой в настройках сети домен `apis.roblox.com`.
   Тогда я сам загружу звуки и текстуры и впишу их ID.
3. **Скриншоты и окно Output.** После каждого теста присылай скриншот и красные строки из
   **View → Output**. Это заменяет мне глаза.
4. **Доступ к сайтам Roblox.** Открой в настройках сети домены `*.roblox.com` и `devforum.roblox.com`.
   Тогда я смогу читать документацию и искать звуки сам.

## Устройство кода
- `ARCHITECTURE.md` — все договорённости: имена моделей, атрибуты, удалённые события, API модулей.
- `src/ServerScriptService/Server/`:
  - `Match` — игровой цикл;
  - `HouseLogic` — двери, окна, укрытия, яблони, свет;
  - `Items` — предметы и магазин;
  - `Lobby`, `Data`;
  - `HouseMap` и `LobbyMap` — постройка карт;
  - `InmateAI` — заключённые.
- `src/ReplicatedStorage/Inmates/` — по одному файлу на заключённого.
- `src/ReplicatedStorage/Client/`:
  - `UI` — экраны, HUD, оповещение;
  - `Controls` — камера, бег, фонарик, предметы;
  - `World` — освещение и атмосфера;
  - `Hide`, `Fx`;
  - `InmatesClient` — анимация заключённых и скримеры.
- Проверка: `sh tools/check.sh` (синтаксис) и `python3 tools/run_mock.py all` (запуск в песочнице).
