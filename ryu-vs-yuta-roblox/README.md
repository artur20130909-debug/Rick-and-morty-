# Рю vs Юта — анимация в Roblox

Фан-анимация боя Рю Исигори и Юты Оккоцу из «Магической битвы».
Часть 1 повторяет присланный клип: 11 секунд, кадр в кадр по таймингу.

- Рю и Юта — обычные блочные персонажи Roblox (R6) в своей одежде.
- Рика собрана из деталей: белое тело в чёрных полосах, пасть с зубами, большие глаза, длинные чёрные волосы, когти.

![Раскадровка](preview.png)

*Это черновой предпросмотр: я отрисовал его своим рендером без Roblox. В Studio будут настоящий свет, неон и контуры.*

## Как запустить
1. Открой `RyuVsYuta.rbxlx` в Roblox Studio: **File → Open from File**.
2. Нажми **Play** (F5).
3. Включи запись экрана: **Win+Alt+R** (Xbox Game Bar) или OBS.
4. Нажми **ПРОБЕЛ** или кнопку **«▶ СТАРТ»**.
5. **R** — посмотреть ещё раз.

Скрипт можно вставить и в своё место. Создай **LocalScript** в
`StarterPlayer → StarterPlayerScripts` и вставь в него код из `RyuVsYuta.client.lua`.

## Звук
Звука в Roblox нет. Тайминг совпадает с клипом, поэтому:
1. Запиши экран.
2. В CapCut положи запись на дорожку.
3. Наложи звук из оригинального клипа с самого начала.

Если загрузишь свой звук в Roblox, впиши его ID в `CONFIG.SOUND_ID`.

## Кадры
| Секунды | Что происходит |
|---|---|
| 0.00–4.83 | Глаза Юты (сверху) и Рю (снизу) в двух полосах. С 4.30 полосы засвечивает. |
| 4.83–5.40 | Белая вспышка столкновения. |
| 5.40–7.83 | Столкновение лучей. Голубой луч Рю идёт слева снизу, розовый луч Рики — из пасти, справа сверху. Летят осколки, камни, красные балки, бьют молнии, сзади зелёный дым. С 7.0 экран постепенно заливает бирюзовая волна. |
| 7.83–8.70 | Общий план ночного города: розово-голубой взрыв. |
| 8.70–10.00 | Юта вытягивает руку, за спиной огромная Рика. Мимо летят голубые и жёлтые полосы. |
| 10.00–11.17 | Рю отбрасывает голубым взрывом. |

## Настройки (`CONFIG` в начале скрипта)
| Настройка | Что делает |
|---|---|
| `DUMMY_MODE = true` | Рю и Юта становятся серыми манекенами без одежды. |
| `AUTO_START = true` | Анимация стартует сразу, без кнопки. |
| `OUTLINES = false` | Убирает чёрный аниме-контур. |
| `SOUND_ID` | ID своего звука из Roblox. |
