# Амиго — нейросеть-друг

Амиго — это нейросеть, которая живёт прямо в браузере. «Амиго» по-испански значит «друг».
Весь Амиго — один файл `index.html`. Его можно открыть на компьютере или на телефоне, интернет не обязателен.

## Как запустить
Открой `amigo/index.html` в браузере (Chrome, Edge, Safari, Firefox). Больше ничего не нужно.

## Что умеет Амиго
- **Болтать.** Понимает около 90 тем разговора: приветствия, «как дела», «кто ты», настроение, шутки, похвалу и так далее.
- **Помнить тебя.** Запоминает имя («меня зовут Артур»), возраст («мне 12 лет»), город и факты («запомни, что я люблю пиццу»). На вопрос «что ты обо мне знаешь» перечисляет всё, что запомнил.
- **Считать.** Понимает «сколько будет 17 × 23», «два плюс два», «корень из 144», «15% от 300», «2 в степени 10», скобки и дроби.
- **Играть.** «Угадай число» (загадывает Амиго), «угадай моё число» (угадывает Амиго), камень-ножницы-бумага, загадки, викторина из 5 вопросов, монетка, кубики, случайное число, «выбери: пицца или бургер».
- **Рассказывать.** Шутки, интересные факты, сказки, стихи, песенки, советы, поддержку. Есть своя мини-энциклопедия: космос, животные, наука, «Рик и Морти».
- **Время и таймеры.** Время, дата, «сколько дней до Нового года», «поставь таймер на 5 минут», «напомни через 10 минут покормить кота».
- **Погода и Википедия** (нужен интернет): «какая погода в Казани», «погода завтра», «кто такой Менделеев».
- **Переводить** слова на английский и испанский и обратно.
- **Голос.** Читает ответы вслух (кнопка с динамиком) и слушает через микрофон, если браузер это умеет (лучше всего Chrome).
- **Учиться.** Если Амиго не понял фразу, нажми «Научить» и напиши правильный ответ. Если ответил не то, нажми «Не то» под ответом. Ещё можно написать: «когда я говорю „пинг“, отвечай „понг“». Нейросеть сразу дообучается прямо в браузере.

## Как устроена нейросеть
Нейросеть написана с нуля на JavaScript, без чужих библиотек (`src/02_nn.js`).

1. Фраза разбивается на признаки: основы слов (стеммер для русского языка), пары слов и кусочки слов по 3 буквы. Кусочки помогают понимать опечатки и разные формы слов.
2. Признаки превращаются в 4096 входов.
3. Дальше идут 64 скрытых нейрона (ReLU).
4. На выходе — вероятность каждой темы (softmax).
5. Обучение — обратное распространение ошибки с оптимизатором Adam, dropout и сглаживанием меток.
6. Обучающие фразы лежат в `src/03_intents.js`, их около 1300. Каждую фразу ещё немного «портим» опечатками, чтобы Амиго их прощал.

Сеть обучается при сборке, а веса встраиваются в `index.html`. Поэтому Амиго запускается мгновенно.

Кнопка **«Мозг»** показывает, как сеть поняла последнее сообщение:
- схему нейронов с силой связей;
- вероятности тем;
- график обучения;
- всё, чему ты научил Амиго.

Там же есть кнопка «Переобучить с нуля»: сеть заново учится прямо в браузере, это занимает 10–30 секунд.

## Супер-мозг Claude (по желанию)
Для сложных вопросов Амиго может спрашивать Claude:
- **Внутри приложения Claude** (если Амиго открыт как артефакт) он спрашивает Claude сам, без ключа. В первый раз Claude попросит разрешение.
- **В обычном браузере** нужен свой ключ Anthropic API. Его вводят в настройках, и он хранится только в этом браузере.

Без супер-мозга Амиго работает сам: ищет ответ в своей памяти, потом в Википедии, а если не нашёл — честно говорит и предлагает научить его.

## Память и приватность
Всё, что Амиго запомнил (имя, факты, выученные фразы, переписка), хранится только в этом браузере (`localStorage`).
Стереть память: «Настройки» → «Забыть всё обо мне».

## Разработка
```
node build.js       # обучает нейросеть, проверяет её и собирает index.html
node test/run.js    # тесты: понимание фраз, калькулятор, игры, обучение, память
```
При сборке видно точность на проверочных фразах из `test/phrases.js`. Нейросеть никогда не видела эти фразы при обучении (сейчас около 96%).

Новая тема добавляется так:
1. Допиши тему в `src/03_intents.js`: примеры фраз `p` и ответы `r`.
2. Запусти `node build.js`.

Файлы в `src/`:

| Файл | Что внутри |
|---|---|
| `00_util.js` | помощники |
| `01_text.js` | очистка текста, стеммер, признаки |
| `02_nn.js` | нейросеть |
| `03_intents.js` | темы и фразы |
| `03b_content.js` | шутки, факты, загадки, викторина, энциклопедия, словарь |
| `04_data.js` | подготовка обучающих примеров |
| `05_skills.js` | калькулятор, время, игры, таймер, перевод, погода |
| `06_online.js` | Википедия, Open-Meteo, Claude |
| `07_brain.js` | логика разговора |
| `08_ui.js`, `09_main.js`, `body.html`, `style.css` | интерфейс |

Шрифты Unbounded, Golos Text и JetBrains Mono подключаются из Google Fonts. Без интернета используются системные шрифты.
