# Amber Alert — фан-ремейк в 3D

Фан-игра по мотивам хоррора **Amber Alert** (TEZ Studios) из Roblox. Это не Roblox: вся игра — один файл
`index.html` с настоящим 3D (three.js), который открывается в браузере на компьютере или телефоне.
Игра не связана с Roblox и авторами оригинала.

## Как это выглядит
- **Лобби**, как в 2.0/3.0. Это ночная площадь:
  - экран экстренного оповещения над точкой появления;
  - киоски «Задания», «Классы», «Скины», «Коды» и центральный **AMBER SHOP**;
  - порталы **LEGACY** и **2.0**;
  - доска рекордов;
  - кабинки запуска матча.
- **Лечебница Black Ridge** за площадью. Там камеры со всеми заключёнными. В каждой камере кровать справа, стальная дверь сзади, номер над входом и планшет-досье с лампочкой. Лампочка зелёная, если ты уже встречал этого заключённого.
- **Дом 1990.** Двухэтажный дом:
  - внизу прихожая, гостиная с ЭЛТ-телевизором, кухня, столовая и гараж (там продавец яблок и электрощиток);
  - наверху три спальни и ванная;
  - позади двор с яблонями.
- **Цикл дня и ночи:**
  - **днём** (7:00–21:00) собираешь яблоки, продаёшь их, покупаешь вещи;
  - **в 21:00** телевизор показывает экстренное оповещение о сбежавшем заключённом и говорит, что делать;
  - **ночью** заключённый вламывается в дом;
  - **рассвет** оживляет погибших.

## Как играть с другом
Есть три способа. Все они работают из одного и того же файла `index.html`.

1. **Онлайн по коду комнаты** (нужен интернет):
   1. Ты нажимаешь «Играть с другом» → «Создать комнату» и получаешь 5-буквенный код, например `KQ7XM`.
   2. Друг открывает у себя тот же файл и выбирает «Войти по коду».
   3. Соединение идёт напрямую между браузерами (WebRTC через бесплатный сервер PeerJS).
   4. Можно открыть комнату и из уже начатой одиночной игры: Esc → «Открыть игру для друга по коду».
2. **Без сервера** (если комнаты не подключаются):
   1. Хост: Esc → «Пригласить без сервера» → отправь другу длинный код через любой мессенджер.
   2. Друг: «Играть с другом» → «Без сервера» → вставляет код и отправляет тебе ответный.
   3. Ты вставляешь ответный код — готово.
3. **Вдвоём на одном экране** (разделённый экран):
   - первый игрок играет на WASD и мыши;
   - второй — на IJKL и стрелках, либо на геймпаде.

Чтобы начать матч, все заходят в одну **кабинку** справа на площади. Через 10 секунд начинается загрузка.

> Если положить файл на любой хостинг (например, GitHub Pages), у хоста появится кнопка «Скопировать ссылку-приглашение» (`...index.html?room=КОД`).

## Механики
- **Укрытия:** шкафы и кладовки. Через 10 секунд в укрытии начинается проверка концентрации: жми E вовремя.
- **Двери** запираются. Заключённые выбивают запертые двери и разбивают окна.
- **Электрощиток** в гараже.
- **Магазин в гараже:** батарейки, дробовик, капканы, перцовый баллончик, шокер, дефибриллятор, аптечка, лампа с датчиком, новые яблони, разбрызгиватель.
- **Директивы ТВ (как в 3.0).** Указание из оповещения проверяется всю ночь. За неподчинение копятся «помехи». На 100% за тобой приходит неуязвимый **Телеведущий** (The Broadcaster). Его можно отключить в настройках («дружелюбный свет»).
- **Классы за Amber:** Новичок, Фермер, Охотник, Медик, Электрик, Бегун.
- **Сложности:** лёгкая (5 ночей), средняя (7), сложная (10), бесконечный режим.
- **Прогресс сохраняется в браузере:** Amber, опыт, ранги (Recruit … Amber Alert), задания, коды.

## Разработка
Исходники лежат в `src/`. Собрать один файл:

```
node build.js            # создаёт index.html
```

- Сторонние библиотеки лежат в `vendor/`: three.js r170 и PeerJS 1.5.5, обе под лицензией MIT.
- Каждый заключённый — отдельный файл `src/12z_<ключ>.js` с записью `INMATES.def({...})`. Контракт описан в начале `src/12_inmates.js`.
- Тестовые параметры адреса:
  - `?test=1&autostart=solo` — сразу начать одиночную игру;
  - `&fast=1` — ускорить время;
  - `&inmate=<ключ>` — выбрать заключённого на ночь;
  - `&peerhost=127.0.0.1&peerport=9000` — свой сервер PeerJS.
